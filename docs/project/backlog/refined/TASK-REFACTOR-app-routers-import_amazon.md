# TASK-REFACTOR-app-routers-import_amazon: app/routers/import_amazon.py: split into a package of modules under 500 lines

## Summary
`app/routers/import_amazon.py` contains the Amazon Prime import endpoints (PRD-0001, PRD-0002), the TMDB matching/confidence logic and small date helpers in one 765-line module. Split it into a package without changing any route, status code or response.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Convert the module into the package `app/routers/import_amazon/`. `app/main.py` keeps working unchanged (`from app.routers import import_amazon`, `import_amazon.router`, mounted at `/api/v1/import`) because `__init__.py` re-exports `router`.

## Decomposition Blueprint
Current size: 765 lines (`wc -l app/routers/import_amazon.py`, matches `.specops/grandfathered_debt.json`).
Current structure (line numbers from the current file):
- Imports and `router = APIRouter(tags=["import"])`: lines 1-44.
- Helpers: `to_naive_utc` (47-56), `parse_release_date` (59-73), `calculate_confidence` (76-112).
- Matching: `match_movies_with_tmdb` (115-307; the only user of `TMDBService`, `TMDBRateLimitError` and the 1s-per-35-requests rate limiting).
- Endpoints under `/amazon-prime/`: `upload_amazon_prime_csv` POST `upload/` (310-390), `get_import_session` GET `session/{session_id}/` (393-438), `add_import_movie` POST `.../movie/{index}/add/` (441-608), `skip_import_movie` POST `.../skip/` (611-663), `update_import_movie_match` PATCH `.../match/` (666-731), `cancel_import_session` DELETE `session/{session_id}/` (734-765).

Proposed modules in `app/routers/import_amazon/`:
- `matching.py` (about 260 lines): `calculate_confidence` and `match_movies_with_tmdb`.
- `session.py` (about 190 lines): its own `router`, `upload_amazon_prime_csv`, `get_import_session`, `cancel_import_session` (imports `match_movies_with_tmdb` from `matching`).
- `review.py` (about 330 lines): its own `router`, `to_naive_utc`, `parse_release_date`, `add_import_movie`, `skip_import_movie`, `update_import_movie_match`.
- `__init__.py` (about 15 lines): `router = APIRouter(tags=["import"])` that includes the `session` and `review` routers; all paths keep their trailing slashes.

## Notes and Risks
- Test patch targets: `tests/test_import_amazon.py` patches `app.routers.import_amazon.TMDBService` (26 sites). `TMDBService` will be looked up in `matching.py`, so the patch string must become `app.routers.import_amazon.matching.TMDBService`. Coordinate with TASK-REFACTOR-tests-test_import_amazon, which moves those tests.
- Keep `import_session_store` imported as a module-level name where the tests expect it (tests import it from `app.services.import_session`, so this is only a concern if a patch is added).
- Only `router` is public from the package; do not re-export the helpers.
