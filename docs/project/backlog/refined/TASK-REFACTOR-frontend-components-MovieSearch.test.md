# TASK-REFACTOR-frontend-components-MovieSearch.test: frontend/src/components/MovieSearch.test.tsx: split into two test files under 500 lines

## Summary
`frontend/src/components/MovieSearch.test.tsx` is 515 lines (25 Vitest tests), fifteen over the limit. Split the single `describe('MovieSearch')` into two test files.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Create a second test file next to the original, named so that Vitest's include pattern (`src/**/*.{test,spec}.{ts,tsx}` in `frontend/vite.config.ts`) picks it up.

## Decomposition Blueprint
Current size: 515 lines (`wc -l frontend/src/components/MovieSearch.test.tsx`, matches `.specops/grandfathered_debt.json`).
Current structure (line numbers from the current file):
- Header comment, imports, `Element.prototype.scrollIntoView` mock, and `renderMovieSearch` helper: lines 1-38. Shared `beforeEach`/`afterEach` (reset mock data, clear token, fake timers): lines 40-50.
- Nested `describe` blocks: `rendering` (52-77), `search behavior` (78-195), `result display` (196-250), `keyboard navigation` (251-383), `mouse interaction` (384-429), `error handling` (430-479), `ARIA state updates` (480-514).

Proposed files:
- `frontend/src/components/MovieSearch.test.tsx` (about 250 lines): keep the header, helper, setup and the `rendering`, `search behavior` and `result display` blocks.
- `frontend/src/components/MovieSearch.interaction.test.tsx` (about 320 lines): `keyboard navigation`, `mouse interaction`, `error handling` and `ARIA state updates`, with its own copy of the ~35-line setup (scroll mock, `renderMovieSearch`, `beforeEach`/`afterEach`). If duplicating the setup is unwanted, move it to a non-test helper module under `frontend/src/__tests__/` and import it from both files.

## Notes and Risks
Both files import `resetMockData`, `setTmdbServiceError`, `MOCK_TOKEN` from `../__tests__/mocks/handlers`, which is itself being split (TASK-REFACTOR-frontend-__tests__-mocks-handlers) but keeps the same import path. The `describe('MovieSearch')` wrapper name can be kept in both files.
