# TASK-REFACTOR-tests-test_import_amazon: tests/test_import_amazon.py: split into several test modules plus a helper module

## Summary
`tests/test_import_amazon.py` (1409 lines, 39 tests) is the largest Python file in the repository. It covers CSV upload, session retrieval, add/skip/re-match of movies, cancelling and the full import flow for the Amazon Prime import (PRD-0001, PRD-0002). The two shared helpers are used by almost every test, so they must move to a shared module and the tests must be split across at least three files.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Split into sibling modules in `tests/` plus a non-test helper module (no package and no barrel re-exports).

## Decomposition Blueprint
Current size: 1409 lines (`wc -l tests/test_import_amazon.py`, matches `.specops/grandfathered_debt.json`).
Current structure (line numbers from the current file; imports at lines 13-18): helpers `create_test_csv` (21-33) and `create_mock_tmdb_result` (36-65); classes `TestUploadCSV` (68-225), `TestGetSession` (228-337), `TestAddMovie` (340-622), `TestSkipMovie` (625-753), `TestUpdateMovieMatch` (756-1081), `TestCancelSession` (1084-1190), `TestFullImportFlow` (1193-1409).

Proposed modules:
- `tests/import_amazon_helpers.py` (about 55 lines, not collected because it does not start with `test_`): `create_test_csv`, `create_mock_tmdb_result`; import them in the test modules with `from tests.import_amazon_helpers import ...`.
- `tests/test_import_amazon_upload.py` (about 400 lines): `TestUploadCSV`, `TestGetSession`, `TestCancelSession`.
- `tests/test_import_amazon_review.py` (about 435 lines): `TestAddMovie`, `TestSkipMovie`.
- `tests/test_import_amazon_match.py` (about 345 lines): `TestUpdateMovieMatch`.
- `tests/test_import_amazon_flow.py` (about 235 lines): `TestFullImportFlow`.
Each module needs the shared imports (`io`, `pytest`, `AsyncMock`/`patch`/`MagicMock`, `AsyncClient`, `import_session_store` from `app.services.import_session`) as used.

## Notes and Risks
The earlier generated plan put 1202 lines in one module, which would itself violate the limit; the grouping above keeps every module under 450 lines. `patch("app.routers.import_amazon.TMDBService")` is used 26 times; if TASK-REFACTOR-app-routers-import_amazon lands first the string must become `app.routers.import_amazon.matching.TMDBService`. Note: this task is still `proposed/`; it needs a refinement pass (confirm the helper import path works under pytest's rootdir/`tests/__init__.py` setup) before moving to `refined/`.
