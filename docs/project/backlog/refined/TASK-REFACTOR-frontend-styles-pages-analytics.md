# TASK-REFACTOR-frontend-styles-pages-analytics: frontend/src/styles/pages/analytics.css: split into three stylesheets under 500 lines

## Summary
`frontend/src/styles/pages/analytics.css` (622 lines) styles the analytics page: activity chart, dashboard grid, stats card, genre/radar chart and rating-distribution chart. Split it by section into stylesheets imported from `frontend/src/styles/index.css` in the same cascade position.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Keep `analytics.css` for the dashboard layout and stats card, and add two sibling files in `frontend/src/styles/pages/`. Add `@import` lines in `frontend/src/styles/index.css` in this order so the cascade is unchanged: `analytics-activity.css`, `analytics.css`, `analytics-charts.css` (replacing the single `@import './pages/analytics.css';`).

## Decomposition Blueprint
Current size: 622 lines (`wc -l frontend/src/styles/pages/analytics.css`, matches `.specops/grandfathered_debt.json`).
Current sections (line numbers from the current file; these are CSS comments, not code symbols):
- `/* Activity Chart */` (1-174).
- `/* Analytics Grid (legacy) */` (175), `/* Analytics Dashboard - 2x2 Grid Layout */` (182), row layout comments (198, 203), desktop layout `>1024px` (208), chart fill (223), `/* Analytics Card Error State */` (237), `/* Stats Card */` (255), `/* Stats Card Responsive */` (357, with a `max-width: 480px` media query): lines 175-381.
- `/* Genre Chart */` (382), `/* Radar Chart */` (414), `/* Rating Distribution Chart */` (501), `/* Rating Distribution Responsive */` (607, `max-width: 480px`): lines 382-622.

Proposed files:
- `frontend/src/styles/pages/analytics-activity.css` (about 174 lines): lines 1-174.
- `frontend/src/styles/pages/analytics.css` (about 207 lines): lines 175-381.
- `frontend/src/styles/pages/analytics-charts.css` (about 241 lines): lines 382-622.

## Notes and Risks
Pure move of rule blocks; do not reorder or edit rules. Keep each responsive `@media` block in the file with its section. Order of the three imports must match the original line order.
