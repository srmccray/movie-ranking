# TASK-REFACTOR-frontend-components-ImportReview: frontend/src/components/ImportReview.tsx: extract search logic and panel to get under 500 lines

## Summary
`frontend/src/components/ImportReview.tsx` is 505 lines, five over the ADR-0002 limit. About two thirds of the file is the inline manual-movie-search feature from PRD-0002 (state, debounced search effect, keyboard handling, selection via `apiClient.updateImportMovieMatch`, and the search panel JSX). Extract that feature so the component only handles the review card, rating, add and skip.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Keep `ImportReview.tsx` in place with the same exported `ImportReview` component and `ImportReviewProps` (it is exported from `frontend/src/components/index.ts` and used by `ImportWizard.tsx`). Add two files; do not convert the component into a directory.

## Decomposition Blueprint
Current size: 505 lines (`wc -l frontend/src/components/ImportReview.tsx`, matches `.specops/grandfathered_debt.json`).
Current structure (line numbers from the current file):
- Props, constants `DEBOUNCE_DELAY` and `MAX_RESULTS`: lines 7-18. State and refs: 20-44 (rating/processing/error plus search state `isSearchMode`, `searchQuery`, `searchResults`, `isSearching`, `searchError`, `highlightedIndex`, `hasSearched`, and refs `inputRef`, `resultsRef`, `debounceTimerRef`).
- Review logic: `currentMovie`, `pendingMovies`, `progress` (46-48), `handleAdd` (50-73), `handleSkip` (75-91).
- Search logic: `performSearch` (94-119), debounced search effect (122-138), scroll-into-view effect (141-149), focus effect (152-157), reset-on-movie-change effect (160-165), `handleSearchOpen` (167-174), `handleSearchClose` (176-183), `handleSelectMovie` (185-220), `handleSearchKeyDown` (222-256).
- Render: empty state (258-264), derived `movie`, `isUnmatched`, `confidenceLabel` (267-269), progress bar, search panel JSX (287-395), review card (397-462), rating (464-481), action buttons (483-503).

Proposed files:
- `frontend/src/hooks/useImportMovieSearch.ts` (about 190 lines, next to the existing `useRankings.ts`): owns the search state, refs, effects and handlers listed above; takes `{ currentMovie, sessionId, currentIndex, onMovieUpdated }` and returns the state and handlers the component and panel need.
- `frontend/src/components/ImportMovieSearchPanel.tsx` (about 130 lines): the presentational search panel JSX (lines 287-395), receiving the hook's values as props.
- `frontend/src/components/ImportReview.tsx` (about 200 lines after extraction): review card, rating, add/skip, composing the hook and the panel.

## Notes and Risks
- Keep all CSS class names (`import-search*`, `import-review*`) and ARIA attributes unchanged; styles live in `frontend/src/styles/pages/import.css` (see TASK-REFACTOR-frontend-styles-pages-import).
- No dedicated unit test exists for `ImportReview`; behavior is exercised only through `ImportWizard`. Run the full Vitest suite, type-check, and manually smoke-test the import wizard search ("Search for different movie", keyboard navigation, cancel) because there is no automated coverage for it.
