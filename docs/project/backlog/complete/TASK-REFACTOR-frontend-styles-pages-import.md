# TASK-REFACTOR-frontend-styles-pages-import: frontend/src/styles/pages/import.css: split into two stylesheets under 500 lines

## Summary
`frontend/src/styles/pages/import.css` (619 lines) styles the Amazon Prime import wizard (upload, review, completion, manual search). Split it into two stylesheets imported from `frontend/src/styles/index.css` in the same cascade position.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Keep `import.css` for the wizard shell, upload, review and completion steps, and move the manual-search styles and the responsive block into a new `import-search.css` imported right after it (replace the single `@import './pages/import.css';` with two lines, `import.css` then `import-search.css`).

## Decomposition Blueprint
Current size: 619 lines (`wc -l frontend/src/styles/pages/import.css`, matches `.specops/grandfathered_debt.json`).
Current sections (CSS comments; line numbers from the current file):
- `/* ==== Import Wizard ==== */` modal sizing (1-14), `/* File Upload Step */` (15), `/* Review Step */` (151), `/* Complete Step */` (333): lines 1-415.
- `/* Import Search (Manual Movie Search) */` (416), `/* Search link button in confidence badge area */` (560), `/* Import Wizard Responsive */` (590; one `@media (max-width: 640px)` block covering `.import-review-card`, `.import-review-poster`, `.import-complete-*`, `.import-search-header`, `.import-review-search-link`): lines 416-619.

Proposed files:
- `frontend/src/styles/pages/import.css` (about 415 lines): lines 1-415.
- `frontend/src/styles/pages/import-search.css` (about 204 lines): lines 416-619.

## Notes and Risks
Pure move of rule blocks; do not edit rules. The responsive block also targets review/complete classes from `import.css`; it stays last (in `import-search.css`) so the cascade order is unchanged. `import.css` at about 415 lines is close to the 400-line warning threshold; if more space is wanted, additionally move the `Complete Step` block (333-415) into a third file imported between the two.
