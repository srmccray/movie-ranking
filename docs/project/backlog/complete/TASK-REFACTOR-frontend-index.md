# TASK-REFACTOR-frontend-index: frontend/src/index.css: delete the unused legacy stylesheet

## Summary
`frontend/src/index.css` (3355 lines) is the old monolithic stylesheet. Commit `f0fb2d6` (2026-01-17, "Refactor CSS into modular file structure") split it into `frontend/src/styles/` and pointed `frontend/src/main.tsx` at `./styles/index.css`. The legacy file is no longer imported anywhere, and `frontend/CLAUDE.md` already calls it a legacy monolith that must not be edited. The cheapest way to retire this debt is to delete the file, not to split it.

Priority: P2. Provenance: Originally generated by `spec-ops health --generate-refactor-tasks` on 2026-10-13; blueprint rewritten by hand on 2026-10-13 after checking the real file structure (the generated blueprint was not usable: wrong symbols, Python-style outputs for CSS/TSX, or sub-modules over the limit).

## Target Decomposition
Delete `frontend/src/index.css`. No replacement files are needed; the live styles are already in `frontend/src/styles/` (`variables.css`, `base.css`, `components/*.css`, `pages/*.css`, `utilities.css`, imported in order by `styles/index.css`).

## Decomposition Blueprint
Current size: 3355 lines (`wc -l frontend/src/index.css`, matches `.specops/grandfathered_debt.json`).
Verification steps before deleting:
1. Confirm nothing imports it: `grep -rn "index.css" frontend --include=*.ts --include=*.tsx --include=*.html --include=*.json -I --exclude-dir=node_modules --exclude-dir=dist` should only show `main.tsx` importing `./styles/index.css`.
2. Confirm no unique rules would be lost: compare class selectors of the legacy file against `frontend/src/styles/**/*.css` (for example with `grep -o '^\.[a-z-]*'` on both and diffing); investigate any selector that exists only in the legacy file. (When this task was reviewed on 2026-10-13, the sets of top-level class selectors in the legacy file and in `frontend/src/styles/**/*.css` were identical; rule bodies were not diffed.)
3. Delete the file, run `cd frontend && npm run build` and `npx vitest run`.

Documentation to update in the same change: `frontend/CLAUDE.md` (lines mentioning the legacy `index.css` at the tree listing, "Do not add styles to the legacy `src/index.css`", and the CSS note), `frontend/README.md` (project tree), and `.claude/agents/frontend-implementation.md` (which still points at `src/index.css` for design tokens; tokens live in `src/styles/variables.css`).

## Notes and Risks
The earlier generated plan proposed `index_part1.py` / `index_part2.py` Python modules for this CSS file; that was a tooling artifact and has been discarded. The legacy file contains styles from before the modularization commit and some later edits to it (commit `1b4a1ec` touched it) may not have been mirrored, which is why step 2 is required.
